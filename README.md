# drillstreak-legal

Public legal/support pages for the DrillStreak app, hosted via GitHub Pages so they have a stable URL without exposing the app's actual source code (which lives in the private `jaywatt01/DrillStreak-` repo).

- Privacy Policy: `legal/privacy-policy.html`
- Terms of Service: `legal/terms-of-service.html`
- Support: `support.html`

Content here should always match the copy in `legal/` and `support.html` in the app repo — copy changes there over when they're updated.
